This folder contains figures and result plots (conductance vs contact fermi energy) from the project. Note:

- [conductance_vs_fermi_energy_(M=360,N=70).png](conductance_vs_fermi_energy_(M=360,N=70).png)   : conductance vs contact fermi energy ($V_g = 0$) for armchair edge config. and square lattice contacts.
- [local_density_of_states.png](local_density_of_states.png)                    : spatial LDOS map, with spatial LDOS map, much higher and more uniform near the van Hove singularity; can be used to calculate current density profiles (**this figure is not included in the report**).
- [conductance_vs_fermi_energy_(M=120,var N).png](conductance_vs_fermi_energy_(M=120,var N).png) : conductance vs contact fermi energy ($V_g = 0$) for $M = 120$ and varying lattice size $N$; dashed line represents $N = 12$, further $N = 24, 36, 72, 96, 108, 120, 148, 200$ and the solid line represents the analytical result. Part (a) to the left considers square lattice contacts and part (b) considers armchair honeycomb lattice contacts.
