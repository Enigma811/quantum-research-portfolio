This folder contains displacement simulations in real space for 1D lattice with non linear additions to the neighbor potential (as for the FPUT model).

The simulations are based on 1D lattice with fixed boundary conditions. The total number of sites includes N + 2 (one
fixed on each end). Each file is named as per the releant paremeters' values. Preffix "imt" denotes very long time of
100000 (10^5) steps, others with 20000 time steps. The step size has been kept uniform across simulations. The
corresponding mode energy profiles have been plotted and can be found [here](../figures/). 

The x-axis denotes the spatial position and y-axis denotes the displacement of particle(s).
