This folder contains selected time-based energy distribution plots for various parameters for the 1D lattice with non linear additions to the neighbor potential (as for the FPUT model, for the project).

The simulations are based on 1D lattice with fixed boundary conditions. The total number of sites includes N + 2 (one fixed on each end). Each file is named as per the releant paremeters' values. Suffix "total_energy" denotes total energy; the suffix "mode_energy" represents the two energy modes. The step size has been kept uniform across simulations. Corresponding real space simulations can be found in real_space_simulations/.

The x-axis denotes time and y-axis denotes the total/mode energy.
